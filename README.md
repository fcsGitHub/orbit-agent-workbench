# 轨道 Agent 工作台 · 0.9

一个真实可运行的 React + Three.js 民用轨道仿真前端。参考 Kimi Code Desktop 的项目/会话、对话和右侧工作区结构，没有复刻其品牌或暗示关联。

## 直接使用

打开 `dist/index.html`（或在项目根目录 `npm start` 后访问 http://localhost:8080）。React、Three.js、图标、场景与 NASA 地球纹理均内置，不依赖 CDN。需要支持 WebGL 2 的现代浏览器；如果图形上下文无法创建，会保留命令、数值、场景和编辑功能并显示原因。

聊天由真实语言模型驱动：DeepSeek 官方 API 的 `deepseek-flash`（DeepSeek-V4.1-Flash），流式输出、可展示真实推理过程，模型提出的工具调用经统一提交链真实执行。构建时从 `keys.txt` 读取 API key 注入产物（`npm run build` 需要 keys.txt 中有 `sk-…` 格式密钥）；也可以在“工具与能力 → 模型连接”中覆盖密钥/模型/Base URL 并做真实连通性测试。没有 mock、演示回退或伪造回复：请求失败时显示官方 API 的真实错误。注意：密钥会进入本地构建产物，仅用于本机离线使用，不要把产物分发到不受信任的环境。

工作区会自动保存到浏览器 localStorage 并在刷新后恢复（仅合成数据；可随时在“工具与能力”中清除并重置）。需要外部留存时导出场景 JSON 或评价 JSON。文件编辑器操作浏览器内的虚拟文件，不访问本机文件系统。

## 工具命令

中央命令输入直接用自然语言与真实模型对话；模型从统一工具目录中选择并真实调用（完整目录见 `src/commands.js` 的 `TOOL_CATALOG`，或在工具与能力对话框中查看），例如：

- “把显示时间设到 900 秒，然后开始播放” → 模型调用 `display.seek` + `display.play`
- “把 Terra-01 的高度改为 650 km，然后保存草稿” → 模型调用 `model.update` + `draft.save`，返回回执号
- “Echo-02 现在的星下点在哪里？光照还是地影？” → 模型调用 `subpoint.query`，回答纬度/经度与明暗状态
- “预检当前版本并冻结实验” → 模型调用 `experiment.preflight` / `experiment.freeze`
- 也可以直接追问：“当前有哪些作业在运行？为什么改高度不会影响已冻结的实验？”

领域动作经统一提交链执行（内容摘要 → CAS → 幂等键 → 回执），显示动作只改呈现；终端控制台保留同一命令集的本地确定性解析（`help`、`status`、`ls`、`cat scene.json`、`seek 900` 等），并明确标注它是本地控制台而非模型。不认识的输入在模型路径中由模型处理，不存在“假装调用语言模型”的本地分支。

## 物理与数据边界

所有场景均为合成示例。运行模型为 e=0 圆轨道解析二体，μ = 398600.4418 km³/s²，R = 6371 km。没有 J2、阻力、日月摄动或机动。坐标是说明性的 ECI 惯性系，不宣称 GCRS 精度。Three.js 轴映射为 x=X、y=Z、z=−Y，全局渲染比例 1/1000；卫星尺寸夸大供选取。RTN 局部屏幕 x=T、y=R、z=N，显示比例 0.015。

UTC 日期仅为显示历元，相对秒驱动演算；未实现高精度时间尺度、闰秒或完整地球定向参数。地表按恒定自转速率显示，底图仅作背景。太阳方向用 Astronomical Almanac 低精度解析式（±0.5°），地影为圆柱本影近似（不含半影），2D 地图的晨昏线按同一低精度太阳几何逐像素判定（无大气折射修正）；过境窗口为固定步进扫描（10 秒近似），地影区间按 30 秒步进扫描定位候选边界后由二分法精化到亚秒（物理模型本身仍是近似），测站为球形地球站心几何。这些只服务显示层与对话查询，不进入实验指标。圆轨道预测与惯性匀速预测相互独立，局部预测参考体采用相同预测假设。没有协方差或误差标定，因此不展示置信区间。

实验指标只消费声明的因素（圆轨道几何、20 秒采样、球形遮挡、事件可用性）；显示预测假设与感知交付模式不进入运行指纹，预检会同时列出“实际消费”与“不消费”的配置。通信判断只检查球形地球遮挡，不代表链路预算。遥感仅天底圆锥与球面几何。事件只改变载荷可用性；不改变轨道。A/B 是可独立配置的前端研究视角，所有数据已在浏览器，绝不提供服务端权限隔离。

## 开发与验证

```sh
npm ci
npm run build   # 构建时从 keys.txt 注入 DeepSeek API key
npm test        # 数值/应用层单测 + DeepSeek 官方 API 真实集成测试（需网络与有效密钥）
npm start       # 本地静态服务 http://localhost:8080
```

`build.mjs` 使用 esbuild 打包成单文件离线 HTML。`tests/domain.test.mjs` 覆盖场景校验、轨道周期与能量、LOS、RTN、事件边界、感知延迟、足迹、太阳方向单位向量与季节赤纬、圆柱地影判定、站心视角（天顶 90°/地平线下）、过境窗口（赤道轨道过赤道测站两窗口、高纬测站不过境）、地影区间（反日向轨道起始于影内、每圈一弧）、日出/日落时刻（二分精化边界与二体理论对照、±1 秒内明暗翻转、端点退化不输出伪事件）、太阳直下点与太阳高度角（直下点回投影与 ECI 太阳方向一致、纬度=赤纬、对跖点为负、极昼/极夜符号）和命令白名单（含 0.9 新增 对象列表/星下点/倍速 解析）；`tests/app.test.mjs` 覆盖应用核心验收场景（对照设计 §43.1 编号）：UX01 双会话 CAS 冲突与三方合并、UX01b 同字段冲突不可自动合并、UX04/UX05 幂等重试与键冲突、UX02 回执归属原会话、UX07 会话归档后作业继续、UX08 显示与运行分离、UX09 暂停边界与 control_revision、UX10 取消 CAS 与分母保留、UX11/UX22 队列与历史结果不受后续编辑影响、UX29 分支去重与 fork、UX34 冻结历史版本、UX36 预检零锁、UX37 冻结重试复用同一把锁，以及版本恢复不倒退历史、比较按案例对齐并声明差异、回执查询只读、快照往返与中断作业恢复后显式继续（含版本不匹配拒绝）。

`tests/llm.test.mjs` 离线覆盖工具名映射、SSE 跨帧解析、UI→API 消息配对、工具 schema 完整性（含 0.9 新增 assets.list / subpoint.query / display.rate 的暴露与参数枚举）、系统提示注入 2D 地图状态与无密钥时的真实报错；`tests/llm.integration.test.mjs` 直连 DeepSeek 官方 API，验证 `deepseek-flash` 真实流式补全与真实工具调用（模型主动请求 `display_seek`），无任何 mock。

交付前构建及 Node 测试（含真实 API 集成测试）通过，并在 Chromium 中完成真实端到端验证：自然语言“把显示时间设到 900 秒然后开始播放”触发模型 3 轮真实工具调用（display.seek → display.play → status 校验真实状态后回答）；“改高度并保存草稿”走 CAS 提交链返回真实回执（rcp-1，head r1→r2）；设置面板“测试连接”返回真实延迟与模型回复；停止按钮、失败路径显示真实 API 错误。jsdom 与 GPU 层面的完整视觉验收仍建议在目标浏览器复查。
